# BOT

After autenticated, user can start the creation of the bot. The bot will only start after user made the payment.

## Emotes

- Owner can select through a list all the emotes it wants
  - A default list with all emotes will be set as default;
  - Owner can remove and or add more emotes by typing the id (name or slug), name and aliases;
- Owner can toggle if the emote will loop.
  - If true owner can configure a keyword to stop the loop (default: !stop)
- Owner can configure a keyword to make all players on the room do a emote without loop (default: !emote-all emote)
- Guests can ask for the emote list any time. It's whispered back to them alone.

## Avatar

- Owner can configure the bot avatar with skins.
- Owner can make the boot "clone" the skin of a target.

## Concierge

Every guest greeted, every regular remembered.
- Viplist


## Warden
